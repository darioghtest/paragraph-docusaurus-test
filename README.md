# Beacon Blog (Docusaurus)

Docusaurus site using the classic preset's blog plugin (docs disabled), deployed to GitHub Pages.

- Posts: `blog/YYYY-MM-DD-<slug>.md` with frontmatter (`title`, `description`, `slug`, `tags`, `authors`); authors live in `blog/authors.yml`
- Static files: `static/` (post images in `static/img/`)
- Live site: https://darioghtest.github.io/paragraph-docusaurus-test/blog/

```sh
npm install
npm start
```
